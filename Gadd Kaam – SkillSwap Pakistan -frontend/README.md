# Gadd Kaam – Frontend

React 19 single-page application built with Vite and Tailwind CSS v4.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Copy `.env.example` to `.env`:
```env
REACT_APP_API_URL=http://localhost:5000
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Run Development Server
```bash
npm start
```
Starts the Vite development server with Hot Module Replacement (HMR) at http://localhost:3000.

### 4. Build for Production
```bash
npm run build
```
Generates production-ready optimized assets in the `dist` directory.

### 5. Preview Production Build
```bash
npm run preview
```
Previews the production build locally.
